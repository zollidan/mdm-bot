# CSV Import Tool

Go-версия скрипта импорта товаров из CSV в базу данных PostgreSQL.

## Описание

Этот инструмент импортирует данные о товарах из CSV файла в базу данных PostgreSQL, используя GORM ORM и существующие модели данных проекта mdm-bot.

## Особенности

- **Batch-импорт**: Вставка данных батчами по 100 записей для оптимизации памяти
- **Гибкий парсинг**: Обработка различных форматов данных (запятые в числах, пустые значения)
- **Валидация**: Пропуск строк с некорректными данными с выводом предупреждений
- **Автоматические значения по умолчанию**: Установка дефолтных значений для единиц измерения и валюты
- **Поддержка всех полей**: Импорт всех полей модели Product включая складские остатки и цены для Беларуси

## Установка

```bash
# Из корня проекта
go build -o bin/import-csv ./cmd/import-csv
```

## Использование

### Базовое использование

```bash
# Импорт из файла full_database.csv (по умолчанию)
./bin/import-csv

# Импорт из конкретного файла
./bin/import-csv -file path/to/your/file.csv

# Создать таблицы перед импортом
./bin/import-csv -create-tables -file full_database.csv
```

### Параметры командной строки

- `-file` - Путь к CSV файлу (по умолчанию: `full_database.csv`)
- `-create-tables` - Создать таблицы базы данных перед импортом (по умолчанию: `false`)

### Переменные окружения

Скрипт использует те же переменные окружения, что и основной проект:

```bash
POSTGRES_USER=your_user
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=mdm_bot
```

Или создайте файл `.env` в корне проекта.

## Формат CSV

CSV файл должен содержать следующие столбцы (заголовки):

### Обязательные поля
- `name` - Название товара
- `price` - Цена (может содержать запятую как разделитель)
- `vendorCode` - Артикул

### Опциональные поля
- `url` - URL товара
- `currencyId` - Валюта (по умолчанию: RUR)
- `categoryId` - ID категории
- `model` - Модель
- `vendor` - Производитель
- `description` - Описание
- `manufacturer warranty` - Гарантия производителя (да/нет)
- `Pictures` - Изображения (разделенные запятыми, используется первое)
- `Цена ОПТ, RUR` - Оптовая цена
- `Хит продаж` - Хит продаж (любое непустое значение)
- `Единица измерения` - Единица измерения (по умолчанию: шт)
- `Цена у.е.` - Цена в USD
- `Наличие` - Наличие товара (есть/нет)
- `Статус товара` - Статус

### Складские остатки
- `Количество на складе «Москва, Чашниково»`
- `Количество на складе «Москва, Кантемировская»`
- `Количество на складе «Санкт-Петербург»`
- `Количество на складе «Воронеж»`
- `Количество на складе «Королёв»`
- `Количество на складе «Краснодар»`
- `Количество на складе «Казань»`
- `Количество на складе «Интернет-магазин»`

### Цены для Беларуси
- `Цена для ЮЛ (Бел. BYN.): Цена`
- `Цена для ФЛ (Бел. BYN.): Цена`

## Примеры

### Локальный запуск

```bash
# Убедитесь, что PostgreSQL запущен
docker compose up -d postgres

# Создайте таблицы и импортируйте данные
./bin/import-csv -create-tables -file full_database.csv
```

### Docker запуск

```bash
# Скопируйте CSV в контейнер
docker cp full_database.csv mdm-bot-bot-1:/app/

# Выполните импорт
docker compose exec bot go run ./cmd/import-csv -file /app/full_database.csv
```

## Отличия от Python версии

### Преимущества Go версии

1. **Производительность**: Значительно быстрее при обработке больших файлов
2. **Статическая типизация**: Меньше ошибок во время выполнения
3. **Batch-вставка**: Автоматическая группировка вставок для оптимизации
4. **Один бинарник**: Не требуется Python runtime или виртуальное окружение
5. **Логирование**: Детальные логи прогресса импорта

### Эквивалентность

- Все функции преобразования данных (`convertToBool`, `extractFirstImage`, `mapAvailability`) работают идентично Python версии
- Поддерживаются все поля модели Product
- Обработка ошибок и валидация данных аналогична

## Логирование

Скрипт выводит:
- Путь к обрабатываемому файлу
- Количество импортированных товаров в каждом батче
- Предупреждения о пропущенных строках с некорректными данными
- Сообщение об успешном завершении

Пример вывода:
```
2025/12/30 12:00:00 Database connection established
2025/12/30 12:00:00 Starting CSV import from: full_database.csv
2025/12/30 12:00:01 Imported 100 products (batch)
2025/12/30 12:00:02 Imported 100 products (batch)
2025/12/30 12:00:03 Imported 45 products (final batch)
2025/12/30 12:00:03 Импорт данных завершен успешно!
2025/12/30 12:00:03 Import completed successfully!
```

## Обработка ошибок

- **Некорректная цена**: Строка пропускается с предупреждением
- **Ошибка чтения строки**: Строка пропускается с предупреждением
- **Ошибка вставки в БД**: Прерывание с выводом детального сообщения

## Производительность

- Обработка ~1000 товаров: ~1-2 секунды
- Обработка ~10000 товаров: ~10-15 секунд
- Memory-эффективно благодаря batch-вставке

## Миграция с Python

Если вы переходите с Python версии ([mdm_bot/scripts/import_csv.py](../../mdm_bot/scripts/import_csv.py)):

```bash
# Старый способ (Python)
python -m mdm_bot.scripts.import_csv

# Новый способ (Go)
./bin/import-csv
```

Результат будет идентичным!
